Cómo funciona

Tus datos siguen guardándose localmente. Cuando inicias sesión, puedes sincronizarlos con las tablas exclusivas de esta app en Supabase.

La seguridad usa Row Level Security (RLS): cada usuario solo puede leer y modificar sus propios registros.
